### 6. In-Game Zone Extraction (November 2025)
**Discovery:** Ascension has **custom continents** not in Wowpedia!

**Custom Continents Found:**
- **Aszaa Archipelago** (Continent ID: 5) - Custom Ascension content
- **Figure Northrend** (Continent ID: 6) - Custom Ascension content

**Standard Continents:**
- Kalimdor (ID: 1)
- Eastern Kingdoms (ID: 2)
- Outland (ID: 3)
- Northrend (ID: 4)

**API Functions:**
```lua
-- Get all continents (including custom Ascension ones)
GetMapContinents()  -- Returns: [1]=ID, [2]=Name, [3]=ID, [4]=Name...

-- Get zones for a continent
GetMapZones(continentID)  -- Returns: [1]=Zone1, [2]=Zone2...

-- Current location
GetZoneText()        -- "Durotar"
GetSubZoneText()     -- "Valley of Trials"
GetMinimapZoneText() -- Usually matches subzone
```

**Tools Available:**
- `utilities/ZoneExtractor.lua` - Full zone extraction script
- `utilities/TestZoneAPIs.lua` - API testing script
- Command: `/extractzones export` - Exports to SavedVariables

**Implications for v2.3:**
- ✅ Wowpedia covers standard WoW zones (71 zones, 1114 subzones)
- ⚠️ **Missing Ascension custom zones** (not in Wowpedia)
- 🔮 **v2.3 Feature:** Extract + merge custom zones with Wowpedia base
- 📊 **Benefit:** 100% zone coverage including Ascension exclusive areas

**Documentation:** `docs/development/ZONE_EXTRACTION.md`

### Feature 3: Addon Split (AscensionVanity + AVDB)
**Priority:** Medium  
**Complexity:** Medium  
**Rationale:** Separate scanner from core addon

**Proposed Structure:**
```
AscensionVanity/ (Main Addon)
├── Core.lua
├── VanityDB.lua (database)
├── CollectionProgressFrame.lua
├── RegionalGuide.lua
├── Settings.lua
└── ... (user-facing features)

AscensionVanity_Database/ (Optional Scanner)
├── APIScanner.lua
├── ScannerUI.lua
├── ExportTools.lua
└── ... (developer tools)
```

**Benefits:**
- ✅ Lighter weight for most users
- ✅ Clear separation of concerns
- ✅ Easier to maintain
- ✅ Optional dev tools

**Considerations:**
- ⚠️ Dependency management (AVDB requires AV)
- ⚠️ SharedMedia or LibStub for communication
- ⚠️ Distribution complexity (2 addons)

**Decision:** Post-v2.3 (not urgent)

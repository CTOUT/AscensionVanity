## Lua Structures (In-Game)

### AscensionVanityDB (SavedVariables)

User configuration saved by WoW client.

```lua
AscensionVanityDB = {
    enabled = boolean,              -- Enable/disable addon
    colorCode = boolean,            -- Color-code tooltip text
    showLearnedStatus = boolean,    -- Show learned status in tooltips
    showRegions = boolean,          -- Show region/location info
    debug = boolean,                -- Enable debug logging
    
    categoryFilters = {
        beast = boolean,            -- Show Beast pets (Group 16777217)
        demon = boolean,            -- Show Demon pets (Group 16777218)
        undead = boolean,           -- Show Undead pets (Group 16777220)
        dragonkin = boolean,        -- Show Dragonkin pets (Group 16777224)
        elemental = boolean         -- Show Elemental pets (Group 16777232)
    },
    
    combatBehavior = string         -- "normal", "minimal", or "hide"
}
```

**Field Names**:
- ✅ `beast`, `demon`, `undead`, `dragonkin`, `elemental` (correct)
- ❌ NOT `totem`, `pet`, `dragons`, etc.

### AscensionVanityDump (API Scan Export)

Generated by APIScanner.lua when user runs `/av scan`.

```lua
AscensionVanityDump = {
    AddonVersion = string,          -- e.g., "2.1-dev"
    AscensionVersion = string,      -- Ascension build (e.g., "2025-11-01 @ 16:21:03 GMT")
    GameBuild = string,             -- e.g., "12340"
    GameBuildDate = string,         -- e.g., "Jun 24 2010"
    GameVersion = string,           -- e.g., "3.3.5"
    LastScanDate = string,          -- ISO format "YYYY-MM-DD HH:MM:SS"
    ScanVersion = string,           -- e.g., "2.1"
    TotalItems = number,            -- Total items scanned
    
    APIDump = {                     -- ⚠️ ALWAYS LAST for readability
        [itemId] = {
            itemid = number,            -- Game item ID (primary key)
            name = string,              -- Item name
            creaturePreview = number,   -- Creature ID (0 = vendor/special)
            group = number,             -- Group ID (category identifier)
            icon = string,              -- Icon filename (lowercase)
            description = string        -- Drop location description
        }
    }
}
```

**Important Notes**:
- `APIDump` dictionary is indexed by `itemId` (number)
- Field order in metadata is alphabetical, `APIDump` comes last
- Icon names are lowercase (e.g., `"inv_misc_bone_01"`)
- Group IDs identify categories (see Category Mappings below)

### VanityDB.lua (Generated Database)

Final optimized database loaded by addon.

```lua
-- Metadata (comments at top of file)
-- Generated: YYYY-MM-DD HH:MM:SS
-- Total Items: N
-- Source Scan: [scan metadata]
-- Categories: Beast, Demon, Elemental, Dragonkin, Undead
-- Group IDs: 16777217, 16777220, 16777218, 16777224, 16777232

AV_IconList = {
    [index] = "icon_filename_lowercase"  -- Sorted alphabetically, indexed from 1
}

AV_VanityItems = {
    [itemId] = {
        itemid = number,            -- Game item ID
        name = string,              -- Item name
        creaturePreview = number,   -- Creature ID (0 = vendor/unavailable)
        description = string,       -- Drop location ("" if unknown)
        icon = number,              -- Index into AV_IconList
        
        -- NEW v2.2: Quest-Locked NPC Information (optional)
        questLock = {               -- Only present for quest-locked NPCs
            questId = number,           -- Quest ID (e.g., 5381)
            questName = string,         -- Quest name (e.g., "Hand of Iruxos")
            lockType = string,          -- "completion", "phase", "daily", "weekly"
            faction = string,           -- "Horde", "Alliance", "Both"
            warning = string,           -- Custom warning message
            notes = string              -- Additional context (summon method, etc.)
        }
    }
}
```

**Field Differences from APIDump**:
- `group` → removed (filtered during generation)
- `icon` (string) → `icon` (number index into AV_IconList)
- Icons are deduplicated in `AV_IconList`

## JSON Structures (Processing)

### API_to_GameID_Mapping.json

Direct export from Lua scan, used for enrichment.

```json
[
    {
        "DbItemId": 123456,         // Game item ID
        "Name": "Item Name",        // Full item name
        "CreatureId": 12345,        // Creature ID (can be 0)
        "Category": "Beast",        // Combat pet category
        "Description": "Location"   // Drop description (can be "")
    }
]
```

**Category Values** (exact match required):
- `"Beast"` (Beastmaster's Whistle, Group 16777217)
- `"Demon"` (Summoner's Stone, Group 16777218)
- `"Undead"` (Blood Soaked Vellum, Group 16777220)
- `"Dragonkin"` (Draconic Warhorn, Group 16777224)
- `"Elemental"` (Elemental Lodestone, Group 16777232)

---

### MasterFullValidated.json

Enriched master file with descriptions.

```json
[
    {
        "DbItemId": 123456,
        "Name": "Item Name",
        "CreatureId": 12345,
        "Category": "Beast",        // PascalCase
        "Description": "Drops from X in Y"
    }
]
```

**Same structure as API_to_GameID_Mapping.json** but with enriched descriptions.

---

### CreatureIdCorrections.json

Manual corrections for creature ID mismatches.

```json
[
    {
        "itemId": 123456,
        "itemName": "Full item name for reference",
        "wrongCreatureId": 98766,
        "correctCreatureId": 2959,
        "reason": "High ID doesn't exist, verified via db.ascension.gg",
        "verifiedBy": "https://db.ascension.gg/?item=123456",
        "dateAdded": "YYYY-MM-DD"
    }
]
```

Used by description enrichment scripts.

Used during VanityDB.lua generation.

```powershell

    name = [string]
    creaturePreview = [int]     # 0 for vendor items
    description = [string]      # Empty string if unknown

```

## Category Mappings

### Group ID to Category Name

**CRITICAL**: These mappings must be consistent across all systems.

| Group ID  | Category Name | Item Name             | Config Key  |
|-----------|---------------|-----------------------|-------------|
| 16777217  | Beast         | Beastmaster's Whistle | `beast`     |
| 16777218  | Demon         | Summoner's Stone      | `demon`     |
| 16777220  | Undead        | Blood Soaked Vellum   | `undead`    |
| 16777224  | Dragonkin     | Draconic Warhorn      | `dragonkin` |
| 16777232  | Elemental     | Elemental Lodestone   | `elemental` |

**Usage Rules**:
- **Lua config keys**: lowercase (`beast`, `demon`, `undead`, `dragonkin`, `elemental`)
- **JSON Category field**: PascalCase (`"Beast"`, `"Demon"`, `"Undead"`, `"Dragonkin"`, `"Elemental"`)
- **Display text**: PascalCase (`"Beast"`, `"Demon"`, etc.)
- **Code comments**: Can use either, but prefer PascalCase for clarity

## Validation Rules

### Required Fields

**APIDump entries MUST have**:
- `itemid` (number > 0)
- `name` (non-empty string)
- `group` (number, one of the 5 Group IDs)
- `icon` (non-empty string)

**Can be empty/zero**:
- `creaturePreview` (0 for vendor items)
- `description` (empty string if unknown)

### Field Name Case Sensitivity

**In Lua**: Field names are case-sensitive strings
```lua
item["itemid"]  -- ✅ Correct
item["ItemId"]  -- ❌ Wrong (nil)
```

**In JSON**: Keys are case-sensitive
```json
{ "DbItemId": 123 }  // ✅ Correct
{ "dbItemId": 123 }  // ❌ Wrong field name
```

**In PowerShell**: Property names are case-insensitive
```powershell
$item.ItemId    # ✅ Works
$item.itemid    # ✅ Also works (same property)
```

## Schema Evolution

When adding new fields:

1. **Document here first** with example values
2. **Update all producers** (scanners, generators)
3. **Update all consumers** (loaders, processors)
4. **Version the schema** (add to metadata)
5. **Test with real data**

When renaming fields:

1. **Never rename** existing fields (breaks compatibility)
2. **Add new field** alongside old one
3. **Deprecate old field** with migration period
4. **Remove old field** after at least one major version

## Common Field Name Mistakes ⚠️

**Incorrect → Correct**:
- `ItemId` → `itemid` (Lua lowercase)
- `DbItemId` → `DbItemId` (JSON PascalCase)
- `dragons` → `dragonkin` (category name)
- `totem` → (no such category)
- `pet` → (no such category, all are combat pets)
- `Icon` → `icon` (field names are lowercase in Lua)
- `GroupId` → `group` (in APIDump scan data)
